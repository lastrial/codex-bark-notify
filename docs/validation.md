## 已知边界

仅支持异步问题卡片，不接入同步 request_user_input、普通文字问句或权限审批。问题 accepted 只代表应用接受卡片，不证明推送到达时仍未回答。

事件输入上限 64 KiB，聊天名称上限 4 KiB。超限或缺少必要身份和名称时跳过。标题采用处理事件时查询到的值。

已打开的聊天可能缓存先前配置。首次配置应在已加载新设置的聊天中验证。Bark API 接收与手机实际显示是两个不同的验收步骤。
